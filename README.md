
# Skin Type Detection – Expert System

## 📌 Project Overview

**Skin Type Detection – Expert System** is a rule-based expert system developed using C++ to identify facial skin types based on user-provided characteristics. This project applies the **Certainty Factor (CF) method** to support the decision-making process and determine the confidence level of the classification results.

The project demonstrates the application of artificial intelligence concepts and computational logic to a skincare-related problem.

## 🎯 Objectives

- Develop an expert system to help users identify their facial skin types.
- Implement the Certainty Factor method to calculate confidence levels.
- Apply computational logic to process user inputs and generate classification results.
- Explore the practical application of artificial intelligence in a real-world problem.

## ⚙️ Methodology

### Certainty Factor (CF)

The Certainty Factor method represents the degree of confidence in a hypothesis based on available evidence.

The general formula is:

`CF(H,E) = MB(H,E) - MD(H,E)`

Where:

- **CF (Certainty Factor):** Confidence value of a hypothesis based on evidence.
- **MB (Measure of Belief):** Degree of belief in a hypothesis.
- **MD (Measure of Disbelief):** Degree of disbelief in a hypothesis.
- **H (Hypothesis):** A possible skin type classification.
- **E (Evidence):** Characteristics provided by the user.

The specific calculation and rule-combination process depend on the implementation in the source code.

## 🔄 System Workflow

1. **Input:** The user provides information about facial skin characteristics.
2. **Knowledge Processing:** The system evaluates the input against predefined rules.
3. **Confidence Calculation:** The Certainty Factor method is applied to evaluate possible conclusions.
4. **Classification:** The system determines the most relevant skin type based on its rules.
5. **Output:** The system displays the classification result.
